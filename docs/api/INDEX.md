# Consumed API endpoints (index)

This frontend **consumes** a REST API owned by a separate backend repository. The authoritative contract is the backend's OpenAPI schema, committed here at `src/lib/api/openapi.yml` and turned into types at `src/lib/api/schema.d.ts` (generated by `npm run api:types`, locked by `scripts/check_types_drift.sh`). This file is just the human-readable index of which endpoints which features call — detail lives in the schema.

| Method | Path | Consumed by (feature) | Notes |
|--------|------|------------------------|-------|
| GET | /api/v1/todos/ | todos | list todos |
| POST | /api/v1/todos/ | todos | create a todo (body: `{ title }`) |

> Refresh the contract from the backend with `npm run api:pull && npm run api:types`, then review the diff (a breaking change needs an ADR).
